# Digital Clock

A simple and responsive Digital Clock application that displays the current time in real-time with a clean user interface.

## Features

- Displays current time
- Real-time clock updates
- Simple and clean design
- Responsive layout
- Easy to use interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Description

This project is a digital clock application developed using HTML, CSS, and JavaScript. It uses JavaScript date and time functions to display the current time dynamically and updates automatically.
